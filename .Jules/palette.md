## 2024-06-25 - Semantic Breadcrumbs and Accessible Icons
**Learning:** This repository extensively uses hardcoded HTML across multiple files (like `capo-polizia.html`, `qualifiche.html`). A common pattern here is using generic `<div>` tags for navigation elements like breadcrumbs, along with decorative FontAwesome icons lacking accessibility context. Converting these to semantic `<nav>` elements, hiding decorative icons with `aria-hidden="true"`, and indicating active state with `aria-current="page"` significantly improves screen reader compatibility without altering the visual CSS structure.
**Action:** When working on navigation components in static HTML repositories, always look for opportunities to upgrade `<div>` tags to `<nav>`, manage decorative icon visibility to screen readers, and identify active page elements using standard ARIA patterns. Ensure modifications are applied to all relevant files since there is no central templating system.
