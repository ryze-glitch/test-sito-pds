## 2024-05-28 - Breadcrumb Navigation Accessibility
**Learning:** In static HTML templates without a JS framework, breadcrumbs are often just styled `<div>` elements. To make them fully accessible according to WAI-ARIA standards, they must be wrapped in a `<nav aria-label="Breadcrumb">` landmark, use `aria-hidden="true"` on decorative separators, and mark the active page with `aria-current="page"`. When modifying string sequences across multiple static files, using Python in binary mode correctly preserves diverse line endings without causing massive git diff noise.
**Action:** When evaluating navigational elements in similar static HTML codebases, verify if they use semantic `<nav>` landmarks. If not, converting them is a high-value, low-risk micro-UX improvement.
