## 2024-07-06 - Flexible Focus Rings
**Learning:** Hardcoding a `border-radius` inside a global `:focus-visible` CSS rule (e.g., `a:focus-visible, button:focus-visible`) overrides the natural shape of elements when they receive focus. This causes pill-shaped buttons or completely circular elements to temporarily become squarish (4px radius) when tabbed to, creating a jarring micro-UX issue.
**Action:** Let `:focus-visible` inherit the element's base `border-radius` naturally, relying only on `outline`, `outline-offset`, and `box-shadow` for focus visualization. Avoid enforcing a fixed border-radius on global focus rules.
